方法论

行研报告自动生成工作流

将行业研究报告的完整生产链路拆解为 AI 可执行的标准化工序—— 从模糊的决策需求到可追溯的分析结论，用提示词工程将行研经验固化为可重复跑的工作流。

  • 全景：决策需求 → 分析框架设计 → 数据采集/治理/打标 → 指标体系建立 → 定量定性融合 → 结论输出
  • 结论分子池：将每条结论标准化为独立"分子"——含数据来源、可信度标签、适用范围，报告撰写时按需取用，每条结论可追溯
  • 指标体系设计：先定义分析框架（构念级），再拆解为具体指标（计算级），确保每个数字都指向一个具体的商业问题
提示词工程工作流设计SOP
工具

数据分析 AI 工作流 · 数据打标节点优化

Python + 大模型协同架构：固定逻辑由 Python 直接执行，仅判断与推理环节调用大模型， 大模型返回可执行代码完成处理，而非逐条数据调用。

  • 单次任务 Token 消耗压至百万以下，成本降至 几毛钱级别（DeepSeek 模型）
  • 设计 Python + LLM 协同架构：规则匹配/格式转换走 Python，推理判断走大模型
  • 保证标注质量的同时将运营成本降至极低，方案已被团队沿用
